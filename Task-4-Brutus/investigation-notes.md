# Task 4 — Brutus SSH Brute-Force Investigation

## Overview

This task involved investigating an SSH brute-force attack using the Brutus Sherlock investigation on Hack The Box.

The investigation focused on analyzing authentication activity, identifying suspicious login attempts, determining attack indicators and reconstructing the sequence of events.

**Platform:** Hack The Box  
**Investigation:** Brutus Sherlock  
**Category:** Incident Investigation / Network Security  
**Status:** Completed  
**Questions Completed:** 8/8

## Investigation Objectives

The investigation was performed to:

- Analyze SSH authentication activity
- Identify repeated failed login attempts
- Determine suspicious source activity
- Identify successful authentication following brute-force attempts
- Extract relevant attack indicators
- Understand the sequence of the SSH attack

## Investigation Methodology

The investigation involved reviewing the available logs and authentication events to identify abnormal login patterns.

The analysis focused on:

1. Reviewing SSH authentication events
2. Identifying repeated failed authentication attempts
3. Correlating failed and successful login activity
4. Identifying relevant source information
5. Reconstructing the attack sequence
6. Documenting the investigation findings

## Investigation Result

The Brutus investigation was completed successfully with all **8/8 questions** answered.

The investigation demonstrated the process of identifying SSH brute-force activity through authentication-log analysis and correlating suspicious login events.

## Key Security Indicators

The investigation focused on indicators including:

- Source IP addresses
- SSH authentication attempts
- Failed login events
- Successful login events
- User accounts involved
- Authentication timestamps

## Conclusion

The Brutus Sherlock investigation provided practical experience in analyzing SSH authentication activity and identifying indicators associated with brute-force attacks.
